# syukatsu-mypage-box-support

「就活マイページ箱」のGitHub Pages用サポートサイトです。外部ライブラリ、Cookie、Analytics、広告を使用しない静的HTMLで構成しています。

## 公開想定URL

- トップ／Support: <https://k-ogawa-k.github.io/syukatsu-mypage-box-support/>
- Privacy: <https://k-ogawa-k.github.io/syukatsu-mypage-box-support/privacy.html>
- Terms: <https://k-ogawa-k.github.io/syukatsu-mypage-box-support/terms.html>

GitHub Pagesの公開が確認されるまで、上記URLを公開確認済みとは扱いません。

## 公開前の設定

`config.js`の`contactEmail`だけ、確定した問い合わせ先へ置き換えてください。未設定のままでもページには「お問い合わせ先は準備中です」と表示され、PLACEHOLDER文字列はユーザー向けに表示されません。

## GitHub Pages

GitHubリポジトリのSettings → Pagesで、Sourceを「Deploy from a branch」、Branchを`main`、フォルダを`/ (root)`に設定します。
